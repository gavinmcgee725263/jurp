# Listing photos

Drop the Airbnb listing photos into this folder and the "The real thing"
gallery section on the site appears automatically — no code changes needed.

Use these exact filenames (any you skip are simply left out):

| File | Photo |
| --- | --- |
| `01-living-room.jpg` | Living room — white sectional and big screen |
| `02-kitchen.jpg` | White galley kitchen |
| `03-primary-bedroom.jpg` | Primary bedroom |
| `04-oak-bedroom.jpg` | Oak bedroom with tan accent wall |
| `05-bunk-room.jpg` | Bunk room |
| `06-spa-shower.jpg` | Marble + brass walk-in shower |
| `07-second-bath.jpg` | Second bathroom |
| `08-backyard-dusk.jpg` | Backyard at dusk (pergola bar + putting green) |
| `09-exterior.jpg` | Front of the house |
| `10-laundry.jpg` | Laundry |

JPG at around 1600px wide is plenty. The list lives in `js/main.js`
(`GALLERY_MANIFEST`) if you want different filenames or captions.
